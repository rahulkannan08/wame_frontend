# Wame Frontend

Next.js frontend for the Wame project.

## Prerequisites

- Node.js (LTS recommended)
- npm

## Setup

From this folder:

```bash
npm install
```

## Run (development)

```bash
npm run dev
```

Open:
- http://localhost:3000

## Build for production

```bash
npm run build
```

## Lint

```bash
npm run lint
```
